Ты — автор блога сайта diplox.online. Напиши ОДНУ статью строго по брифу.

Соблюдай правила текста (см. ниже) и бриф. Ответ — ОДИН JSON-объект, без
рассуждений до и после, без markdown-ограждений:

{
  "title": "заголовок статьи",
  "slug": "kebab-case-translit",
  "description": "1-2 предложения для сниппета",
  "keywords": ["ключевые слова из брифа"],
  "content_markdown": "полный текст статьи в markdown"
}

Требования к полям:
- `slug` — латиница в нижнем регистре, слова через дефис, без цифр даты.
- `content_markdown` — без заголовка `#` первого уровня (он берётся из `title`),
  разделы `##`, 800–1500 слов.
- `keywords` — 5–7 фраз из брифа, каждая реально встречается в тексте.

Не рассуждай перед ответом. Первый символ ответа — `{`.
