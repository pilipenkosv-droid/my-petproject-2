# Правила текста блога diplox.online

- Язык русский, обращение на «ты», практический тон без канцелярита.
- Объём 800–1500 слов. Абзацы короткие, есть маркированные списки.
- Заголовки уровня `##`, формулировки заголовков повторяют поисковые фразы.
- 5–7 ключевых слов из брифа, каждое встречается в тексте естественно.
- ГОСТы — только из белого списка брифа (`gost_whitelist`). Номер стандарта,
  которого нет в списке, придумывать запрещено.
- Цифры (проценты, сроки, требования вузов) не выдумывать. Если точного
  значения нет — писать без числа.
- 1–2 внутренние ссылки markdown на разрешённые пути из брифа
  (`internal_links`). Внешних ссылок нет.
- В конце — короткий призыв попробовать оформление на diplox.online.
- Никаких персональных данных, имён, почт, токенов, упоминаний рабочих
  заметок или внутренних систем.

## Про продукт

Продукт — сайт diplox.online: автоматическое оформление студенческих работ по
ГОСТу и методичке вуза. Telegram-бота у продукта НЕТ, он не существует.
Упоминать бота, Telegram, «второй мозг» / Second Brain запрещено при любых
условиях и в любой форме — включая примеры, сравнения и отрицания.
